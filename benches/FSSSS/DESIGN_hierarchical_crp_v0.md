# DESIGN · hierarchical CRP 最小例（H-g4/5/6）

> 承 `pcs_struct_growth.py`（单层开列、parent 手贴、子树手写）。目标：把「结构级生长」从**单层手工**
> 升为**多层自发**。**判据先冻后用**（园律 5）。账：`benches/FSSSS/pcs_hier_crp.py` · `report_pcs_hier_crp.json`。

## 0 · 现状与缺口
`pcs_struct_growth` 证了「组合黑天鹅 → 开新节点」可行，但：① 深度恒 1（新节点不会**再**开子）；
② parent 手贴；③ 子树（红/圆/甜）手写。本 v0 用**递归 CRP**补这三样。

## 1 · 模型（阈值驱动 nCRP）
- 每节点带 **prototype** 向量 `p_v`、**计数** `n_v`、**浓度** `α`。
- 插入观测 `x`：自根下行。在节点 `v`：
  - 若存在子 `c` 使 `cos(x, p_c) ≥ τ` → **下行**到 `argmax`；`n_c += 1`。
  - 否则 → 在 `v` 下**开新子**（`p_new := x`，`n_new := 1`），停。
- **权重**（每节点自守）：`w_c = n_c / (N_v + α)`，归一；全局叶先验 = 根先验 × 沿路径 `w` 累乘。
- **连续属性**（叶内）：对连续标量用 **DP-mixture** 开高斯分量
  （`∝ n_k/(N−1+α)` 复用 ／ `∝ α/(N−1+α)` 开新）。

## 2 · 观测流（构造，可复算）
义素维 3 维，方向即语义：
```
A=(1,0,0)  B=(0,1,0)  C=(0.5,0.5,0)   # C = A、B 的等比混合
C1=(0.6,0.4,0)        # C 的近亲（应作 C 的子）
C2=(0.4,0.6,0)
```
`τ=0.9`。序列：`A, B, C, C1, C2`。

## 3 · 冻结判据
- **H-g4（递归开列）**：树**深度 ≥ 2**（`C` 先为新生叶，`C1` 再在其下开子）；**各节点 Σw=1**。
- **H-g5（parent 自动）**：新节点的 parent＝**下行路径**所定（记录 path，可复算；非手贴）。
- **H-g6（连续开新分量）**：叶 `C1` 内连续属性开 **≥2** 个高斯分量（DP-mixture）。

## 4 · 失败条款（照登）
- H-g4 败（深度恒 1）⇒「递归开列」不成立；
- H-g6 败（分量恒 1）⇒ 退化为「固定子树」。

## 5 · 非此
- 非「真 CRP 概率采样」（v0 取**阈值驱动**的确定性版本，为可复算；概率版候 v1）；
- 非真语料（合成向量，为判据可控）。

