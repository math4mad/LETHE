## 1. 问题（一句）

FSSSS 模糊几何与园引擎（余弦似然×贝叶斯）是否只是**排序同构**、都缺概率语义？
PCS 补上 `p(x|C)=μ_C(x)/size(C)` 那步除法后，能否带来园引擎做不到的**模型选择**
（留出边际似然选 c）？

## 2. 条件矩阵

| ID | 名称 | 设置 | 种子 |
|----|------|------|------|
| C1 | 园引擎 | 义素基向量 + 截断余弦似然 × 贝叶斯后验 | 确定性（无随机源） |
| C2 | FSSSS | 凸体核心 + 指数隶属 μ=μ₀·exp(−c·d)，Jaccard 相似 | 确定性 |
| PCS | 补除法版 | p(x\|C)=μ_C(x)/size(C)，真后验 ∝ p(x\|C)·p(C) | 确定性 |

## 3. A Priori Interpretation Rules

| 结果 | 解释 | 下一步 |
|------|------|--------|
| bridge 排序一致 ≥ 0.75 | 两机器排序同构：都在算几何相似 | 主张成立，进 PCS |
| 0.5–0.75 | 部分同构 | 查分歧探针（哪个词撕裂） |
| < 0.5 | 不同构 | 两机器算的不是一回事，重审主张 |
| **一致率与 0.5 基线差 ≤ 0.1（无差异带）** | **平手 = 无信号** | 不作结论，加大探针集 |
| PCS 归一化 rel_err ≤ 0.01 | 那步除法实现正确 | 继续 |
| rel_err > 0.05 | 除法实现有 bug | 先修实现再谈主张 |
| PCS 单步/序贯 argmax 一致 ≥ 0.75 | PCS 与园引擎兼容 | 主张成立 |
| < 0.5 | PCS 与园引擎不同构 | 查先验/似然差异 |
| 边际似然最优−最差 c 总证据差 ≥ 20 nats | 模型选择有效（园引擎做不到的补白） | 补白主张成立 |
| **差值 ≤ 5 nats（无差异带）** | **选择无效：c 不可辨识** | 补白主张不成立 |

## 4. 证伪条件

- 排序一致 < 0.5，或 PCS 归一化 rel_err > 0.05 → 核心主张（排序同构 + PCS 补白）被证伪。
- 模型选择判别力 ≤ 5 nats → 「PCS 带来模型选择」这条补白不成立。
