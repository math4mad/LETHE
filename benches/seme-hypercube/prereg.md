## 4. 证伪条件

- C1 hardest_token_acc < 0.40 → 「义素图上可学」不成立，先查装置（不变量门限）再查主张。
- **第四格消融（C4：DeepWalk 初始化 + 冻结嵌入）**（2026-10-15 主人裁定增补，判别实验）：补齐「嵌入学习 × 嵌入有义素结构」2×2 矩阵缺格（学习✗ 结构✓）。装置同 C3（DeepWalk 在 Hamming 边集初始化），随后嵌入层 `requires_grad=False`。判据三态：
  - C4 hardest ≥ 0.95 → **结构本身足以承担能力**（学习非必要，C3 结论推广）；
  - C4 hardest ≈ C2（≤ 0.35）→ 学习仍必要，结构只是先验；
  - C4 介于 C2/C3 之间 → 结构与学习各贡献部分。
  与 C1/C2/C3 横比（同图，hop 量纲一致）。
- **α 插值扫描预设**（2026-10-15 主人裁定，跑前写死判据，扫完只填数、不改判据）：同一 Hamming 图内，嵌入 = α·DeepWalk + (1−α)·random，α ∈ {0, 1/6, …, 1}（7 档，同 Proust-Squid 扫描）。判据三选一：
  - **单调增** → 「注入越多越好」在 Hamming 图成立（与原文 path-star 一致，与 Proust-Squid 倒 U 相反）；
  - **倒 U 形** → 存在最优注入量 α*（与 Proust-Squid 同形，「注入量最优」问题成立，α* 即答案）；
  - **单调减** → 任何注入均损害（DeepWalk 几何与该任务冲突）。
  速度门限按新形式：相对加速比 ≥ 10×；各档记录 steps_to_90 与 hardest（best-ckpt）。
- hop 2–6 对齐 ≥ 0.40 → 「几何是浅的」被证伪（这是义素组最有价值的潜在翻案点）。
- 界面实验 acc 提升 < 0.05 → 「接口瓶颈」主张在语义图下不成立。
- 装置不变量门限（gates.json 第一批）任一不过 → 装置有 bug，一切训练结论无效。

- **α 插值对象可比性前提**：Proust-Squid 的 α 扫描（P4 单维链图）与拟议的 Hamming 图 α 扫描中，「α」同名但**插值对象不同**——α 插值的是「各自图上的 DeepWalk 嵌入」，两图 DeepWalk 嵌入的几何（有效秩、hop 结构）不同。倒 U 形结论跨图成立的前提是两图插值对象可比；Hamming 图 α 扫描须独立验证倒 U 形是否存在，不可把 P4 图的 α=0.5 峰值平移过来。

## 6. D0 界面实验臂规格（方向性格式，2026-10-15 冻结，先于首跑）

**缘起**：原文 Phase 1.8b（llm-geometry-analysis
`notebooks/08_phase1_8_directional.ipynb`）—— 单一格式变化
（输入携带方向性上下文）使 acc 从近零到满分（C1/C2
0 → 1.000，C3 → 0.940），不改权重、不改架构。界面实验
检验：「接口瓶颈」主张在语义图（义素超立方体
Hamming H(4,4)）下是否成立。

**格式（唯一变量）**：
- C1：边样本 `[EDGE] u [SEP] v [EOS]`（对称邻接）＋ 路径样本
  `[PATH] leaf [SEP] hops… [EOS]`（根→叶单向）
- D0：三元组 `[EDGE] prev curr [SEP] next [EOS]`
  （方向性转移；预测位 = logits[3]，与原文 1.8b 位置
  约定一致；首 hop 以 `[BOS]` 作 prev）

**数据集（知识源与 C1 同，唯格式不同）**：
1. **游走三元组**：每条有向边 (u→v) × 全部前驱语境
   p ∈ N(u)\{v} ＋ 起始语境 `[BOS]` —— 对应 C1 的全边集
   边样本（36,864 条）；
2. **路径三元组**：**训练**路径（191 叶）双向典范测地线
   （根→叶与叶→根）—— 对应 C1 的路径样本（1,120 条）。

**与原文 1.8b 的一处有意差异（审阅者注）**：原文取
**全部**路径（含测试叶）的三元组；本臂只取训练路径，
以保持与 C1 同等的「未见组合」泛化需求 —— 否则 D0
hardest 是对测试叶首跳的记忆而非泛化，与 C1 0.583
不可比。原文的 1.000 在该口径下含测试臂记忆成分；
本臂测的是纯界面效应。

**训练/评估**：同 C1（8 层 d256，lr 2e-4，wd 0.01，
batch 8 × grad_accum 4，40k 步，seeds 42/43/44；训练期
评估 = 方向性格式最难 token `[EDGE] [BOS] leaf [SEP] →
父节点`；best-ckpt 按 hardest_token_acc 选取，口径同
C1）。专有度量：`traversal_full_acc` / `traversal_per_hop`
（teacher forcing 叶→原点方向性遍历，行为量）；其余
度量（嵌入几何 *_h）与 C1 同口径。

**判据（§4 已冻）**：Δhardest = D0_hardest（best-ckpt）−
C1_hardest（best-ckpt = 0.5833）：
- Δ ≥ 0.50 → 「接口瓶颈」在语义图下**普遍成立**
  （§3 锚：原文 0→1.0）；
- 0.05 ≤ Δ < 0.50 → 部分成立（界面有贡献但非充分）；
- Δ < 0.05 → 「接口瓶颈」主张在语义图下**不成立**
  （证伪）。
辅助观察（不作判据）：traversal_per_hop 形态、hop 2–6
对齐相对 C1 的变化。

**gates.json 增补（与本节同冻）**：
`D0_hardest_token_acc ≥ 0.40`（方向性格式可学性下限，
与 C1 同锚；未过 = 方向性格式本身不可学，先查装置）。

**装置/回收**：同夜航纪律（Kaggle GPU，`_materialize_vendor`
舱内还原 11 个 vendor 文件，`*.pt` 训完即清，哨兵
`NIGHT-DONE` ×1 + `REPORT_LINE` ×4）。

## 7. E 臂 —— α 注入量插值扫描（七档，Hamming 图，2026-10-15 冻结，先于首跑）

**问题**（承 Proust-Squid 首飞倒 U 形与夜航 C3 全注入
近满分之张力）：同一 Hamming 图内，DeepWalk 几何的
**注入量**与能力的关系曲线是什么形？「什么注入量
最优」——α* 即答案（若有）。

**条件**：E0..E6，α = i/6（i = 0..6），嵌入初始化
`emb(α) = α·DW + (1−α)·rnd_s`：
- **DW**：DeepWalk（gensim skip-gram，Hamming 边集
  `to_orig_graph`，walk_length 10 / walks_per_node 40 /
  window 5 / seed=训练种子）——与 C3 逐 seed 同源，故
  **α=1 ≡ C3（恒等端点）**；
- **rnd_s**：`rnd ~ N(0,1)`（`np.random.default_rng(
  1000·i + seed)`，条件×种子确定性）按**全局行范数
  匹配**缩放到 DW 尺度：`rnd_s = rnd · mean‖DW‖₂ /
  mean‖rnd‖₂`。

**尺度匹配的必要性（Proust-Squid scale_ctrl 病灶的
移植预防）**：gensim DW 原生行范数远小于默认
`nn.Embedding` 初始化（N(0,1)，d=256 时行范数 ≈16），
C1/C3 的嵌入尺度本不同。若不匹配，acc(α) 曲线同时
混入「结构比例」与「尺度」两轴，不可解释。本臂把
**尺度钉在 DW 轴**上，α 纯控结构比例。辅助观察
（非判据）：α=0（DW 尺度纯随机）vs C1（默认尺度
自组织）——差值即**尺度效应**的量级估计。

**特殊 token 行**：不特判——α=1 时 emb(α) = DW
（特殊 token 行 = 0，与 C3 恒等）；α<1 时
`(1−α)·rnd_s` 自然填充（与 C1 默认初始化行为一致）。

**装置**：stage1_local_core 形制（8 层 d256 / n_head 8 /
lr 2e-4 / wd 0.01 / batch 8 × grad_accum 4 / 40k 步 /
max_seq_len 12），C1 对称格式数据集（edge_path_mix
1.0），3 seeds（42/43/44）。训练期评估与 best-ckpt
口径同 C1（hardest_token_acc）。每条件追加
**init_probe**（训练前对 emb(α) 的 arm_cluster_acc 与
按跳数聚类 acc）——各档初始结构含量的协变量。

**判据（§4 已冻，扫完只填数）**：3-seed 均值
hardest(α) 曲线形态三选一：
- **单调增** → 「注入越多越好」在 Hamming 图成立
  （与原文 path-star 一致，与 Proust-Squid 倒 U 相反
  ——两图定义是调节变量）；
- **倒 U 形** → 存在最优注入量 α*（与 Proust-Squid
  同形，「注入量最优」问题成立，α* 即答案）；
- **单调减** → 任何注入均损害（DW 几何与该任务冲突）。
速度观察：各档记录 steps_to_90（达 90% 者）与
hardest（best-ckpt）；相对加速比按新形式（C1 未达
90%，以 40k 步上界作分子 → 下界）。

**门限（本节冻结，E 臂构建入 gates.json 时入册）**：
E0..E6 各档 `hardest_token_acc ≥ 0.40`（逐档可学性；
某档不过 = 该注入量破坏可学性——本身即发现）。

**审阅者注**：
1. E 臂与 D0 正交（E = 初始化几何量，D0 = 输入界面
   格式）；E 臂跑 C1 对称格式。若 D0 证伪「界面瓶颈」
   （Δ<0.05），E 臂绝对值仍有效（同格式横比）；若 D0
   大幅解锁，E 臂结论需注明格式前提。
2. 与 Proust-Squid α 扫描的同名性：两处「α」插值
   对象不同（P4 链图 DW vs Hamming 图 DW），且本臂
   尺度匹配、Proust-Squid 随机分量取 0.02 缩放——
   倒 U 形不可跨图平移，须独立验证（prereg §4 审阅者注
   已立）。
3. α=0 ≠ C1（尺度不同）：α=0 是「DW 尺度纯随机」
   基线；C1 是「默认尺度自组织」基线。两者差值记录
   为尺度效应，不作曲线形态判据。
